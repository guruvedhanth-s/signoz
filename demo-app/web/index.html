Rates are deliberate. At 100% the good-path metric stops being emitted entirely, so the SLO completeness gate cannot tell "everything failed" from "telemetry stopped" and the agent correctly refuses to diagnose. Use ~80% for a diagnosable incident; use 100% to demonstrate the refusal on purpose.
